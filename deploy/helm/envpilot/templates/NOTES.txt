EnvPilot is installed as a direct Helm umbrella release.

The release namespace is the EnvPilot workload namespace. Helm directly owns
the enabled control-plane, frontend, Agent and Runner resources; no installer
Job, nested Helm invocation, or cluster-wide installer RBAC is created.

Frontend service:
  envpilot-frontend (or envpilot-frontend.fullnameOverride when configured)

Same-cluster Agent and Runner are disabled by default. Enable either only after
supplying its project-scoped registration Secret through envpilot-agent or
envpilot-runner values. For a remote execution cluster, install the published
envpilot-agent or envpilot-runner chart there instead.

Migration from the retired installer-Job release is documented in:
  https://github.com/envpilot/deploy/blob/main/deploy/helm/envpilot/README.md
