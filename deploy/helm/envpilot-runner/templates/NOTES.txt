Auth persistence:
  Bootstrap tokens are one-time credentials. The chart persists the runnerAuthToken
  returned by registration on a PVC by default so rollout-created pods do not
  reuse bootstrap tokens.

  To use an externally managed Secret instead, configure:

    controlPlane.authPersistence.existingSecret
    controlPlane.authPersistence.runnerAuthTokenKey

  On restart the runner should load ENVPILOT_RUNNER_AUTH_TOKEN from that Secret
  and skip bootstrap registration. Rotate by creating a new deployment
  instruction/token set and updating the persisted Secret.

Migration from the retired envpilot-runner-chart OCI chart:
  Older releases used the fixed resource name and immutable selector
  envpilot-runner-chart. Preserve the existing Deployment, RBAC and
  envpilot-runner-chart-auth PVC with:

    helm upgrade {{ .Release.Name }} oci://ghcr.io/envpilot/envpilot-runner \
      --namespace {{ .Release.Namespace }} --reuse-values \
      --set fullnameOverride=envpilot-runner-chart \
      --set legacyChartName=envpilot-runner-chart

  New releases intentionally receive independent names and auth PVCs. Do not
  assign either legacy setting to a second release in the same namespace.
